# Публикация новой версии Court Assistant

## Подготовка (один раз)

1. **Создай GitHub-репозиторий** и запушь туда проект.

2. **Замени плейсхолдер** в `package.json`:
   ```json
   "publish": {
     "provider": "github",
     "owner": "YOUR_GITHUB_USERNAME",   ← вставь свой ник/организацию
     "repo": "court-assistant"
   }
   ```

3. **`GITHUB_TOKEN`** — токен уже доступен в GitHub Actions автоматически,
   никаких дополнительных секретов добавлять не нужно.

---

## Выпуск новой версии

### 1. Обнови версию в `package.json`

```json
"version": "1.7.0"
```

### 2. Закоммить и запушь

```bash
git add package.json
git commit -m "chore: bump version to 1.7.0"
git push
```

### 3. Создай и запушь тег

```bash
git tag v1.7.0
git push origin v1.7.0
```

После этого GitHub Actions автоматически:
- соберёт приложение (`electron-vite build`)
- упакует его в NSIS-инсталлятор (`electron-builder --win --x64`)
- создаст GitHub Release с тегом `v1.7.0`
- загрузит туда `.exe`, `.blockmap` и `latest.yml`

### 4. Проверь Release на GitHub

Перейди в **Releases** → убедись, что файлы загружены и релиз **не Draft**.
Если релиз черновой — опубликуй его вручную (кнопка «Publish release»).

## Как работает автообновление у пользователей

| Событие | Что происходит |
|---|---|
| Запуск приложения | Через 5 секунд после показа окна идёт тихая проверка `latest.yml` |
| Новая версия найдена | Появляется баннер «Доступна новая версия vX.Y.Z» с кнопкой «Скачать» |
| Нажата кнопка «Скачать» | Начинается загрузка инсталлятора, отображается прогресс-бар |
| Загрузка завершена | Баннер предлагает «Перезапустить и установить» |
| Нажата кнопка «Установить» | Приложение закрывается, запускается NSIS-инсталлятор |
| Если пользователь закрыл баннер | Инсталлятор запустится автоматически при следующем закрытии приложения |

## Локальная сборка без публикации

```bash
npm run build:win
```

Готовый инсталлятор появится в папке `release/`.
